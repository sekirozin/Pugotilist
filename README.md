# PugotiList

Catálogo pessoal de jogos, filmes e séries integrado à identidade central PugotiLab.

## Desenvolvimento

```bash
npm install
npm run dev
```

Variáveis necessárias para catálogos reais:

- `TMDB_READ_TOKEN`: token de leitura da aplicação TMDB.
- `IGDB_CLIENT_ID` e `IGDB_CLIENT_SECRET`: aplicação Twitch usada pelo backend.
- `PUGOTILAB_PROFILE_URL`: endpoint interno do perfil central.

As credenciais pertencem ao serviço. Usuários acessam exclusivamente com suas contas PugotiLab.
